# AutomateX Aquatic Studio — Full Stack Web & Automation Platform

AutomateX Aquatic Studio is a modern, full-stack web application designed for real estate and inventory management, featuring automated client broadcasting via WhatsApp Web, live public showcases, and secure database handling.

---

## 🚀 Key Features

* **Real-Time Inventory Management:** Add, view, and manage property listings, plots, and luxury assets.
* **Automated WhatsApp Broadcast:** Blast instant inventory updates and live public links directly to all saved clients in the SQLite database.
* **Public Client Showcase:** Mobile-friendly, secure public catalog (`/public/listings`) with direct WhatsApp inquiry buttons linked to custom agents.
* **Dynamic Ngrok Integration:** Automatically detects local network IPs and active Ngrok public HTTPS tunnels for seamless live sharing.
* **Automation Backend:** Built-in background background triggers and robust SQLite database persistence.

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask, SQLite
* **Frontend:** Tailwind CSS, HTML5, Jinja2 Templates, FontAwesome Icons
* **Automation & Tools:** PyAutoGUI, Webbrowser, Requests, Socket
